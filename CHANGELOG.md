# Changelog

## 1.0.0

First native release: a SwiftUI port of the Glaze YT Curator app.

- Browse saved channels and loadouts; aggregated home feed (Videos / Live / Channels) with sort and Hide watched
- Stage playlist edits (add, remove, reorder) and Sync them to YouTube
- Drag videos onto the playlist, with Add to top / Add to bottom drop zones
- Asks before re-adding a video you already completed
- Import subscriptions, manage loadouts, follow channels from playlist rows
- Mini avatar rail when the sidebar is collapsed
- Imports channels and loadouts from the Glaze version on first launch
- Built-in updater (YT Curator → Check for Updates…)
